首个正式版本。APK 用固定的 release key 签名，之后的版本可以直接覆盖升级。

## 更快、更省电

- **INT8 模型包 v2（默认）**：旧包里 local 图展开的 17 步 transformer 只有 1 步被量化（共享权重经过 `Identity` 节点，量化工具跳过了），现在全部 int8；local 图的 text head 只算用到的 2 个 logit（等价改写）。local 图每帧耗时降到原来的 40–55%。
- **线程按负载拆分**：逐帧 LM 改为 2 线程自旋池（实测比 4 线程快约 30%，还少占两个核），prefill 用独立 4 线程池保证首音延迟，codec 独立 2 线程。
- **只用大核**：推理线程绑定到大核（运行时识别，排除小核簇），并以音频优先级创建。
- codec 领先 3 秒以上时按 16 帧一批解码，每帧 codec 开销更低。

ARM64（Armv9，dot-product / i8mm）实测同一句 7 秒音频：首音 107 ms，RTF 0.21，LM 12.7 ms/帧（v0.1 默认配置：249 ms / 0.43 / 28.5 ms）。

## 修复

- codec 线程在最后一批解码出错时，调用方会永远卡住
- 合成过程中释放模型（切换模型、释放内存、空闲释放）会阻塞界面直到整段读完（ANR）
- 纯数字 / 时间文本（如「12:30」）被当成英文朗读；英文里的「10-20」读成 minus
- INT8 模型包更新后 App 不会重新下载；残留的 `.part` 文件导致下载失败
- 来电时还在继续朗读；系统 TTS 里日语音色的语言标记错误
- 下载模型时不必要地中断正在进行的朗读
- 模型下载固定到经过验证的 Hugging Face 版本

## 质量

INT8 v2 由 CI 对照官方 FP32 检查：图改写无损；hidden state 余弦相似度均值 0.998；在 ARM64 上按 FP32 模型给生成结果打分，INT8 v2 比 FP32 高 1.4%，与旧 INT8 包在误差范围内相同（也就是更快但没有更差）。对音质不满意可以随时在「模型」里切回 FP32。

## 安装

下载 `MossTtsNano-v0.2.0.apk` 安装，打开后在「模型」里下载 INT8（约 540 MB，国内选 hf-mirror）。
