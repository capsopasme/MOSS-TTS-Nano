适配 ColorOS 16，修一个系统 TTS 连接时可能卡住的问题。可直接覆盖安装升级，模型无需重新下载。

## ColorOS 16

作为系统 TTS 引擎时，MOSS 是被阅读器、语音助手等别的 App 叫起来的，往往还在后台、熄屏时。ColorOS 会冻结后台应用，还会拦住一个 App 去启动另一个 App（“关联启动”），不放行的话别的 App 可能连不上引擎、只显示文字不出声。

- 新增「后台运行」卡片：显示是否受电池优化限制，一键“取消电池优化”，并说明 ColorOS 还要在应用详情里打开的“允许自动启动”“允许关联启动”“允许完全后台行为”。
- 「系统 TTS 引擎」卡片会显示 MOSS 现在是不是系统首选引擎；不是的话给出 ColorOS 上最快的设置方法（系统设置里搜“文字转语音”，或用 root 一条命令 / 语音助手里一键设置）。“打开系统 TTS 设置”在找不到原生设置页的系统上会依次退到无障碍、系统设置首页。

## 修复

- **别的 App 连接引擎时可能卡住几秒**：音色列表读取时要等引擎的锁，而加载模型的那几秒一直持有这把锁。比如语音助手开始通话时预热引擎、同时阅读器也连过来，后连的一方要等模型加载完才能完成连接。现在读音色列表不再等锁。
- 系统 TTS 每读一句都会问好几次音色列表，每次都要重新读、解析克隆音色文件；现在缓存起来，文件有增删改才重新读。克隆音色先写临时文件再改名，读列表时不会读到写了一半的文件。

## 安装

下载 `MossTtsNano-v0.3.1.apk` 覆盖安装即可。
