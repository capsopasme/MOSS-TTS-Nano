系统 TTS 跟随 App 里选的音色、修复音色列表看不到最后一项、偏小声的音色自动补偿音量。可直接覆盖安装升级，模型无需重新下载。

## 系统 TTS 跟随 App 里选的音色

之前音色选择会保存，但系统 TTS 只在别的 App 连上引擎的那一刻读取一次：一直连着的 App 在你改了音色之后仍然用旧的；上次选的是英文 / 日文音色时，中文朗读会退回第一个内置中文音色。

现在引擎额外提供 `auto-zh` / `auto-en` / `auto-ja` 三个「跟随 App」音色并作为默认音色，每一句话合成时才决定用哪个音色：

- 用的是你在 App 里最近选的、同语言的音色（中文 / 英文 / 日文分别记住，克隆音色算中文）
- 在 App 里改了音色，下一句就生效，不用重启别的 App
- 某个 App 自己指定了具体音色时，仍然用它指定的；指定的克隆音色被删掉后自动退回默认

## 音色列表看不到最后一个音色

音色下拉菜单有 19 项以上，比屏幕还高；安卓 15+ 强制全面屏（edge-to-edge）后，菜单底部会被导航栏挡住，最后一项（通常就是刚克隆的音色）看不到。

改成对话框列表：按「我的克隆音色 / 中文 / 英文 / 日文」分组，打开时直接定位到当前音色。克隆完成后会自动选中新音色。

## 音量均衡：深夜电台等音色不再太小声

MOSS-TTS-Nano 会照搬参考录音的音量，而官方内置音色的参考录音响度相差约 17 dB。用 INT8 模型给 18 个内置音色各生成 7 句实测响度（ITU-R BS.1770）：生成语音的响度和参考录音几乎一致（中位差 -0.1 dB）。

- 偏小声的音色自动补偿到约 -16 LUFS（接近最大声的几个内置音色），大声的不动：**CN 深夜电台 +5.5 dB**、说书 +8 dB、明星 +3 dB；英文 Nathan +9 dB、Trump +6 dB；日文 Soyo +15 dB、Arisa +11.5 dB 等（完整表格见 README）
- 「朗读」卡片新增**音量滑块**：每个音色单独再调 -6～+12 dB，App 内朗读、导出 WAV、系统 TTS 都生效
- 输出端新增零延迟峰值限幅器（-0.5 dBFS）：提高音量不会爆音，模型本身偶尔超过满幅的峰值（以前被硬削波）现在也被平滑限住
- 新克隆的音色在编码前把参考录音归一化到同一响度；v0.3.0 之前克隆的音色没有响度数据，不做自动补偿，可以用音量滑块调，或重新克隆一次

实测（同一句）：深夜电台 -24.1 → -18.6 LUFS，说书 -26.8 → -18.8 LUFS，限幅只在 0～1.7% 的帧上起作用。
