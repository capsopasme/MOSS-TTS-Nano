修复 v0.2.0 在手机上点击朗读必定失败的问题，可直接覆盖安装升级。

## 修复

- **点击朗读报错 `java.lang.ExceptionInInitializerError`，之后一直报 `…TextNormalizer$Robust`**：文本规范化里有一条正则（处理 `{…}` 花括号）的右花括号没有转义。电脑上的 Java 能接受这种写法，但安卓的正则引擎（ICU）认为是语法错误，导致规范化模块初始化失败，任何文本都无法朗读。
- 带 Unicode 字符类标志的几条正则改为在不支持该标志的系统上自动回退（ICU 默认就是 Unicode 语义，行为不变）。

规范化输出与 v0.2.0 在电脑上的结果完全一致，只是现在在手机上也能正常运行。

## 防止再犯

CI 新增检查：引擎里的每一条正则都会用 ICU（安卓实际使用的正则引擎）编译一遍，任何一条不通过就不会发布。之前的桌面 JVM 测试无法发现这类问题。

## 安装

下载 `MossTtsNano-v0.2.1.apk` 覆盖安装即可，已下载的模型无需重新下载。
